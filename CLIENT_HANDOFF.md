# SiNails Studio — Client handoff

## What you receive

- Live app URL: *(paste Railway/Render URL after deploy)*
- Empty database — no staff accounts until you create them
- Full Admin + User (employee) system

## First login (required)

1. Open the live URL in a browser.
2. You will see **Create Admin Account** (first-time setup).
3. Enter your name, email, and password → create the admin.
4. You are signed in as **ADMIN**.

Do not use a temporary password you will forget — this is the studio owner account.

## Create employees (users)

1. While logged in as Admin, open **Users**.
2. Add each employee (or share the public signup link after setup is complete).
3. Employees use **Entries** to record clients, services, amounts, and Cash/Online payments.

## What Admin can see

| Section | Purpose |
|---------|---------|
| Live Activity | Today’s entries from all employees |
| Clients | Clients from employee entries |
| Users | Manage staff accounts |
| Appointments | Studio appointments + status |
| Payments | All Cash/Online payments + totals |
| Reports | Revenue charts and service performance |

## Security notes

- Do not share the Admin password.
- Maximum **2** administrator accounts.
- Employees cannot open Admin Reports / Payments / all-staff data via API.
- Change passwords from **Profile** if needed.

## Support

For hosting issues (site down, domain), contact the person who deployed the app (Railway/Render dashboard access).

For day-to-day studio use, Admin manages Users and monitors Live Activity / Payments / Reports.
